# 日志初始化

日志是出问题时唯一证据。打印要分级，过滤要可配，初始化要放在入口。

## 分级

日志按重要程度分级。调试信息最多，普通信息其次，警告和错误最少。运行时用环境变量选要看到哪一级。

```rust
// 初始化一次，放在程序入口
fn main() {
    std::env::set_var("RUST_LOG", "debug"); // 选级别：debug 以后全打
    // 真实项目用 tracing 订阅器，这里只看形状
    println!("日志已初始化");
}
```

对照 C++：像 `spdlog` 的级别开关。C# 像 `Serilog` 的级别配置。锈语常用 `tracing`，环境变量管过滤，入口只调一次。

## 每一列都要能对齐

每条日志写清四件事：什么时候发生的、哪个模块打的、什么级别、说什么事。缺了哪一件，排查时都要回头翻。

完成标准：入口只初始化一次，级别能靠环境变量改，日志四件套齐。

:::exercise{title="动手：跑两级日志"}
用环境变量分别以低级别和中级别跑一次，看输出条数差多少。再把入口忘掉初始化会发生什么记下来。
:::
