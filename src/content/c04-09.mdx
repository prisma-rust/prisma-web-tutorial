# 给时钟写单元测试

时钟是纯逻辑，给它写测试最省。测试只喂时长，看步进数。

## 喂时长看步进

```rust
// 给时钟写测试：喂固定时长，看切出几格
#[test]
fn step_counts() {
    let mut timer = Timer::new();
    assert_eq!(timer.advance(Duration::from_millis(16)), 1);
}
```

对照 C++：给物理写单测。对照 C#：给时钟写单测。锈语测试和代码放一起写。

完成标准：步进数在测试里写死。
