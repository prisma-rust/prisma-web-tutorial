# 第一个程序

上一课装好了 `cargo`。这一课只做一件事：用 `cargo` 新建一个程序，让它打印一句话并跑起来。

## 新建一个项目

打开终端，运行：

```bash
cargo new hello-engine
cd hello-engine
```

`cargo new` 会生成一个最简骨架：

```text
hello-engine/
  Cargo.toml       # 项目描述：名字、版本、依赖
  src/
    main.rs        # 程序入口
```

`Cargo.toml` 是 Rust 的项目清单，地位对标 C++ 的 `CMakeLists.txt`、C# 的 `.csproj`。它写明「这个程序叫什么、版本是多少、依赖哪些包」。`src/main.rs` 是真正写代码的文件。

打开 `src/main.rs`，内容只有 3 行：

```rust
// 程序入口：Rust 二进制从这里开始执行
fn main() {
    println!("Hello, engine"); // 往标准输出打一行文本
}
```

`println!` 最后那个 `!` 表示它是宏（macro），不是普通函数。宏在编译期展开成代码。C++ 的 `std::cout`、C# 的 `Console.WriteLine` 是运行时函数，Rust 的 `println!` 是编译期展开，格式化在编译期做类型检查。

## 运行它

在项目根目录（有 `Cargo.toml` 的那一层）运行：

```bash
cargo run
```

第一次运行最慢，`cargo` 会下载依赖、编译代码、生成可执行文件。正常输出长这样：

```text
Running `target/debug/hello-engine`
Hello, engine
```

`target/debug/hello-engine` 就是编译产物（Windows 上带 `.exe`）。C++ 下对应 `g++ main.cpp -o hello && ./hello` 的两步，C# 下对应 `dotnet run` 的一步。Rust 把两步合成了一步，中间产物都放在 `target/` 里。

## 两种语言对照：别人怎么打印一句话

放在一起看，三种语言的「最小程序」只差构建方式。

**C++（手写编译）：**

```cpp
// main.cpp —— 需要 g++ 这类编译器手动编
#include <iostream> // 输入输出头文件，C++ 靠 #include 拼
int main() { // 程序入口，返回 0 表示正常退出
    std::cout << "Hello, engine\n"; // 流输出，\n 是换行
    return 0;
}
```

构建要手动两步：`g++ main.cpp -o hello` 编译，`./hello` 运行。`#include` 是文本展开，路径错了编译就停。

**C#（dotnet 一步到位）：**

```csharp
// Program.cs —— dotnet run 一步跑起来
using System; // 命名空间，C# 靠 using 引入
Console.WriteLine("Hello, engine"); // 标准输出
```

`dotnet run` 就做了 `csc` 编译 + 运行两件事，和 `cargo run` 的分工几乎一样。差别是 Rust 的 `println!` 带格式检查，C# 的 `WriteLine` 是重载。

Rust 侧你已经看到的 `println!("Hello, engine")`，括号里是格式化字符串，`{}` 占位会在编译期对参数做类型检查。C++ 的 `std::cout << ...` 把格式抛给了流，C# 的 `Console.WriteLine` 靠方法重载区分。

## 读懂构建命令干了什么

`cargo run` 其实是三件事串起来：

1. 读 `Cargo.toml`，知道程序名和依赖。
2. 调 `rustc` 编译 `src/main.rs`（和依赖）到 `target/debug/`。
3. 执行编译出的二进制，把输出打印到终端。

你以后只需要记 `cargo run`、`cargo build`、`cargo test` 三个命令。`cargo build` 只编译不运行，`cargo test` 只跑测试。下面几个问题帮你确认你真的会用了。

:::exercise{title="动手：改一句并再跑"}
1. 把 `src/main.rs` 里的字符串改成你的名字，重新 `cargo run`，确认输出变了。
2. 故意删掉 `println!` 最后的分号，跑 `cargo run`，看编译器把行号和原因打印出来。记住这个错误长什么样，齿轮卡住时第一时间回去看。
3. 打开 `Cargo.toml`，把 `name = "hello-engine"` 改成别的名字，再 `cargo run`，观察 `target/debug/` 下的新二进制名字。
:::

完成标准：你能不看教程新建一个项目并跑起来。下一课就用这个骨架长出工作区和第一个引擎 crate。
