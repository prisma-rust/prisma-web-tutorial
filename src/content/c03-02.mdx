# 一个游戏引擎片段

这一课只看一个游戏片段：一个对象带位置，带刚体，引用到处传。

## 片段从哪里来

C# 里引擎对象是现成的：新建对象，挂上刚体，改位置。C++ 里自己写结构体和裸指针。Rust里没有现成对象，先把片段的长相在脑子里摆正。

## 照抄对照

对照一和对照二在上一课已经摆好了。片段的意思都一样：对象带变换，带物理，引用和改动随时发生。

差别只在谁管生死。C# 靠垃圾回收，C++ 靠人，Rust靠所有权。

完成标准：你能不看代码说出片段里有哪三样东西。

:::exercise{title="动手：标三样东西"}
在片段里标出变换、刚体、引用各自在哪一行。再说出每一行可能的改动是谁做的。
:::
