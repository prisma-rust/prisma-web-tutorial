# 内部可变性

只读引用也想改时用内部可变性。它把改动藏进一个格子里。

## 藏法

```rust
// 内部可变：只读也能改，改时要查格子
use std::cell::RefCell;
struct Counter { v: RefCell<i32> }
```

对照 C++：像mutable 或裸指针改。对照 C#：像引用改属性。锈语把改动做成一次查格子，格子被借时直接报错。

## 真正要改的不是别用

内部可变性解决的是“外层只读、内层要改”这种场景。普通字段改动别绕过来。

完成标准：你能说出内部可变是查格子，不是魔法。

:::exercise{title="动手：借一次格子"}
用内部可变写一次改动，再故意同时借两次，看运行时怎么报。
:::
