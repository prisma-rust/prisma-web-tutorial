# 索引取代指针

拿到编号之后，拿数据变成按编号查中心表，而不是跟着内存走。

## 查中心表

```rust
// 按编号查表：借整个世界，再按类型切出池子
pub fn get_mut<T: Component>(&mut self, entity: Entity) -> Option<&mut T> {
    if !self.is_alive(entity) {
        return None; // 死实体直接拦掉
    }
    self.pools.get_mut(&TypeId::of::<T>()); // 找到类型池
}
```

所有权集中在世界，访问权是查询切分。两个实体同时改成两次查询切分，而不是两次指针相争。

对照 C++：像用索引查数组。对照 C#：像用字典查对象。锈语把查表变成借用的一部分。

完成标准：你能说出索引为什么能替代指针。
