# 一次固定步进的顺序

一次固定步进只做逻辑。顺序定死，别人才能接上。

## 顺序定死

```rust
// 一次固定步进：输入、逻辑、同步三件
fn step() {
    input::gather(); // 拿输入
    world::step();   // 算逻辑
    world::sync();   // 收尾
}
```

对照 C++：每步先输入后逻辑。对照 C#：每步先更新后同步。Rust把三件顺序写在一个函数里。

完成标准：顺序在函数里看得见。
