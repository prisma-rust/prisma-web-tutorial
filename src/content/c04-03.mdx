# 累加器

累加器把真实时间攒起来，攒够一格就切一个步进。

## 攒满切一格

```rust
// 累加器：真实时间进来，一次切一格步进
let mut bank: Duration = Duration::ZERO;
bank += elapsed; // 攒进来
while bank >= STEP {
    world::step(STEP); // 切一格出来干活
    bank -= STEP;
}
```

对照 C++：像物理累加器。对照 C#：像游戏循环累加器。锈语把格子大小写成常量，格子大小不随帧变。

## 余数留在里面

没切完的余数留在累加器里，下帧继续用。余数丢了，时间就断了。

完成标准：你能说出累加器进、出、余各是什么。

:::exercise{title="动手：看余数"}
给累加器加一句打印余数，跑一遍，看它怎么涨跌。
:::
