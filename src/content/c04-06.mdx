# 丢弃策略

超出的时间总要去哪。丢弃规则先写好，读者才知道卡顿从哪来。

## 丢了只剩卡顿

上限之外的余量直接丢。丢 200 毫秒只等于一次卡顿。追回去等于死锁。

`horizon` 在切法里直接夹住，`prisma-rev` 在循环条件里卡住：

```rust ref="horizon:crates/horizon-client/src/clock.rs#L393-L413"
// horizon 丢弃：夹到 10 以内，夹掉的就是丢弃
let ticks = timer.advance_game_time(now_ms, |d| d.max(mspt));
ticks.clamp(0, 10) // 夹之前是追赶，夹之后是丢弃
```

丢弃的量打不出来也行。关键是规则写在上限那一句，读代码的人一眼看得见。

## 双语对照

C++ 里丢时间直接丢。C# 里丢时间直接丢。两边都把丢弃写在限补那一句。
