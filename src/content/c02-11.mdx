# 第一次运行引擎

到这里骨架有清单、有依赖、有日志、有错误，有时候了。这一课把它们串成一个能跑的引擎入口。

## 入口串起五件事

打开二进制包的入口文件，按五件事的顺序写：

```rust
// 引擎最小入口：初始化 -> 跑步进 -> 停
fn main() {
    println!("引擎启动"); // 1. 日志初始化位置
    for step in 0..3 {
        println!("步进 {step}"); // 2. 固定步进占位
    }
    println!("引擎停止"); // 3. 优雅退出
}
```

对照 C++：像 `main` 里先初始化再进循环。C# 像 `Program.Main` 里先配日志再跑。Rust入口只做串联，不写重逻辑，重逻辑都在包里。

## 跑一次

在工作区根运行：

```bash
cargo run
```

能看到启动、步进、停止三段打印，就说明清单和依赖都对上了。修一个地方跑一次。

完成标准：`cargo run` 一次过，启动到停止都在输出里。

:::exercise{title="动手：改一处再跑"}
改入口里的步进次数，重新运行，看输出跟着变。把这行输出当作引擎的起步线，下一章开始给它接窗口。
:::
