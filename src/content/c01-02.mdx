# 引擎的最小闭环

上一课定了职责边界：引擎隔开五类外部输入，让逻辑只认步进。这一课只回答更小的问题：最小一圈长什么样。

## 先定验收，再写代码

最小闭环有三段：输入、逻辑、画面。少一环就不是引擎：没有输入，引擎聋了；没有逻辑，引擎只会画；没有画面，引擎盲了。

> 最小闭环 = 输入一次 → 逻辑一次 → 画面一次，顺序固定。

验收也只有三条：开着窗口跑十分钟不卡死，步进次数和帧数对得上，关掉窗口干净退出。三条都过，这一圈算闭上了。

## 两仓里这一圈长什么样

`horizon` 的一圈在游戏主循环里，调的顺序固定。`prisma-rev` 的一圈叫单步模拟与提取提交。两边顺序都一样：先算逻辑，再画。

```diagram flow
读输入 -> 算逻辑 {pill}
算逻辑 -> 出画面 {pill}
出画面 -> 读输入 {round}
```

```rust ref="prisma:crates/prism-app/src/app.rs#L1124-L1174"
// 单步模拟与提取提交：完整实现点引用块去看
// 这里手写最小形状：先输入，再逻辑，再出画面

// 1. 输入：帧开始，清空瞬时状态
input.begin_frame();
```

tick_frame 本身只做失败检查，然后调单步模拟：

```rust ref="prisma:crates/prism-app/src/app.rs#L810-L830"
// 每帧自检：渲染线程死了就返回错误，不继续自旋
fn tick_frame() {
    if handle.is_finished() {
        return Some(failure); // 把失败原因带回去
    }
    tick_sim(true); // 然后跑一圈逻辑和提取
}
```

`horizon` 的入口在 `game.rs`，真正干活的是 `tick` 与 `render_frame`。主循环调一次 `tick` 再调一次 `render_frame`，圈就闭上了。按名查：

```rust ref="horizon:crates/horizon-client/src/game.rs#L8195-L8210"
// horizon 游戏侧：tick 与 render_frame 按这个顺序调，完整实现见引用
// tick：算世界 tick；render_frame：画一帧
// 一圈只调这两次，顺序固定
```

两边没写错的地方：逻辑在画之前。画之前没算完，这一帧画的就是上一帧的世界。

## 手写最小示例

```rust
// 一圈入口：读输入 -> 算一帧逻辑 -> 出一帧画面
fn frame() {
    input::poll(); // 读这一圈的输入
    world::step(1.0 / 60.0); // 算一帧逻辑，步长固定
    render::present(); // 画一帧并上屏
}
```

每行注释说清意图。输入读完就清，逻辑按固定步长，画面按渲染那一步上屏。后面章节只给每个函数填实，顺序不换。

## 双语对照

C++ 里同一圈通常是三个调用连着写：

```cpp
// C++ —— 一圈输入、逻辑、画面连着写
int main() {
    while (!should_quit) {
        poll_input(); // 读输入
        step_physics(1.0f / 60.0f); // 逻辑
        present(); // 画面
    }
}
```

编译运行：
```bash
g++ main.cpp -o engine && ./engine
```

C# 里同样一圈连着写，`dotnet run` 跑起来：

```csharp
// C# —— 一圈先输入，后逻辑，再画面
while (!quit) {
    Input.Poll(); // 读输入
    Physics.Step(1f / 60f); // 逻辑
    Renderer.Present(); // 画面
}
```

```bash
dotnet run
```

三边一圈都是三件事。这是从零开始手把手教你的第一靠山：先把圈转起来，再添章节。

## 不该往圈里塞的事

配置读写、存档、热重载这些事，不进这一圈。塞进去，圈就重。配置在启动时一次读完，存档在退出或定时存，热重载在文件监听里。圈只管一圈。

:::tip{title="为什么圈要小"}
圈小才跑得快。圈小了，测试也小：喂一次输入，看逻辑一次，看画面一次。塞大了，改一处就要测全部。
:::

## 跟着看的结果

这一课验收：`cargo run` 能转一圈，输入一次、逻辑一次、画面一次都发生，窗口开着，关掉干净退出。

:::exercise{title="动手：数一数一圈"}
在入口给三件事各加一句打印。跑一次，看三条是否按顺序出现。把顺序和次数抄下来：输入几次、逻辑几次、画面几次。这是后面章节验收的起点。
:::
