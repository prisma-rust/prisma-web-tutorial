# 引擎的最小闭环

最小闭环是引擎的最小一圈：输入进来，逻辑算一次，画面出一帧。少一环就不是引擎。

## 一圈只做三件事

入口里把一圈写成顺序的三件事：

```rust
// 一圈入口：读输入 -> 算一帧逻辑 -> 出一帧画面
fn frame() {
    input::poll();          // 读这一圈的输入
    world::step(1.0 / 60.0); // 算一帧逻辑，步长固定
    render::present();       // 画一帧并上屏
}
```

对照 C++：像主循环里依次调输入、更新、绘制。对照 C#：像游戏里先读输入再更新再渲染。Rust把这一圈写成纯函数调用，后面章节慢慢把每个函数填实。

## 闭环怎么证明能转

最小闭环跑起来只看一条：跑十分钟不卡死、不飘移、不吃掉内存。窗口还开着，画面还在动，步进次数和帧数对得上。

完成标准：`cargo run` 能转一圈，输入一次、逻辑一次、画面一次都发生。

:::exercise{title="动手：数一数一圈"}
在入口给三件事各加一句打印，跑一次，看三条是否按顺序出现。把顺序和次数记下来，这是后面章节验收的起点。
:::
