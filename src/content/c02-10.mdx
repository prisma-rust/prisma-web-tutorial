# 断言与不变量

不变量是代码对自己说的话：一旦它被打破，程序继续跑只会更糟。

## 断言写给程序员看

```rust
// 这一条在调试和发布里都查：半径不能是负数
assert!(radius >= 0.0, "半径为负，调用方给错了");
```

对照 C++：像 `assert()`，在调试里检查。C# 像 `Debug.Assert`。锈语还有 `debug_assert!`，发布版直接跳过。发布版想查的用 `assert!`。

## 不变量放在接口边上

参数进来先断言它在什么范围内。范围写成一句话：路径不能是空的，指针不能是空的，长度不能超过上限。进门先查，帮调用方早暴露。

完成标准：每个公开函数的入口都说得清哪条不变量、破了会怎样。

:::exercise{title="动手：加一条入口断言"}
找一个公开函数，在入口加一条范围断言。故意传一个破界值，确认程序在那一行停下，不再往后跑。
:::
