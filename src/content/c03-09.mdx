# 句柄与内存区

真正的解法是换提问：不找对象在哪，找实体的数据在哪。问一换，答案变成编号。

## 编号不借任何东西

句柄只是一个编号，可以随便复制、存进数组、跨线程传。

```rust
// 句柄只是一个编号，不借对象本身
pub struct Entity {
    pub id: u32,         // 槽位编号
    pub generation: u32, // 代号，回收时加一
}
```

对照 C++：像裸指针，但不指向内存。对照 C#：像对象引用，但不带垃圾回收。

## 代号让旧句柄失效

槽位被回收时代号加一。旧句柄拿着老代号，对不上，自动失效。

完成标准：你能说出句柄为什么比指针安全。

:::exercise{title="动手：回收一次槽位"}
发一个句柄，销毁，再发一个新句柄，对比两代代号差多少。旧句柄再去拿数据，看是不是拿不到。
:::
