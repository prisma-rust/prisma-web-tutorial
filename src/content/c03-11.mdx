# 系统代替方法

行为挂在对象上写不下去，就把行为搬到对象外面，变成自由函数。

## 自由函数只要世界的一部分

```rust
// 系统是自由函数，只借需要的世界
fn movement(world: &mut World, dt: f32) {
    for (entity, pos, vel) in world.query2_mut::<Position, Velocity>() {
        pos.0 += vel.0 * dt; // 就地更新
    }
}
```

对照 C++：像把更新逻辑提成自由函数。对照 C#：像把对象方法拆成系统类。锈语不给对象内部再借世界，行为必须在外面。

完成标准：你能说出系统和对象方法差在哪。

:::exercise{title="动手：拆一个方法"}
把一个对象方法按这课样子搬到外面，参数只留世界和时间。再跑一次，确认结果一样。
:::
