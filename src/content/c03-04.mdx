# 两个可变引用

锈语借用规则只有一句：同一时刻，要么任意多个只读引用，要么恰好一个可变引用。

## 规则管什么

这条规则只管谁在改。写完引用，编译器就知道两个引用会不会打架，不用你写注释。

```rust
// 只读引用可以拿很多份，改的只能拿一份
let a = &obj; // 只读，任意多个
let b = &mut obj; // 可变，只能一份
```

对照 C++：两个可写指针同时指着一块内存是常见写法，靠人盯。对照 C#：两个引用指向同一对象也是常见写法，靠垃圾回收和自觉。锈语把这个自由拿走了，换来判定。

## 先守规则，再写更大结构

后面的父子结构、查询、调度都长在这条上。先记死这条，再看下一课的所有权。

完成标准：你能背出这条规则，并说出它跟线程无关。
