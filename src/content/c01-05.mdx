# 承认自己会死

引擎必须假设自己会失败。失败路径写了，才能在失败里体面地停下。

## 失败先报出来

渲染线程死了，主线程继续自旋会白屏加高占用。检查放在每帧入口：

```rust
// 每帧自检：渲染线程死了就返回错误，不自旋空转
if handle.is_finished() {
    return Some(shared.take_render_failure().unwrap_or("render thread exited".into()));
}
```

对照 C++：设备丢失走错误码。对照 C#：渲染失败抛异常到顶层。Rust走返回值，调用方必须把失败记到日志或界面上。

## 失败也要分级

能恢复的错误继续跑，不能恢复的停下并报原因。报的时候把上下文带上：哪个线程、哪个设备、哪个文件。

完成标准：你能说出引擎里至少一条失败路径怎么报、怎么停。

:::exercise{title="动手：故意让失败露面"}
故意让渲染线程提前退出，看入口的检查能不能把原因打出来。把那行输出保存下来。
:::
