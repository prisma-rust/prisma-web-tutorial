# 时长与瞬间

时长是一段长短，瞬间是一个时刻。两个名字分开，代码才不混。

## 两个名字

```rust
// 时长是一段长短，瞬间是一个时刻
use std::time::{Duration, Instant};
let start = Instant::now(); // 瞬间：现在
let span: Duration = std::time::Duration::from_millis(16); // 时长：16 毫秒
```

对照 C++：像 `steady_clock` 的时间点和持续时间。对照 C#：像 `DateTime` 和 `TimeSpan`。锈语把名字分开，类型直接告诉你能加不能减。

## 瞬间只看前后

瞬间比大小只看谁在前。时长能加能减。拿瞬间去做时长的事，编译器拦住。

完成标准：你能分清这段是时长还是瞬间。
