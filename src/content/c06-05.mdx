# 渲染线程死了

渲染线程死了，主线程自旋只是白屏加高占用。检查在每帧入口。

## 先查线程

```rust
// 渲染线程死了就返回错误，不自旋空转
if handle.is_finished() {
    return Some(shared.take_render_failure().unwrap_or("render thread exited".into()));
}
```

对照 C++：设备丢失走错误码。对照 C#：渲染失败抛到顶层。锈语走返回值。

完成标准：线程死法有名字，日志里能查。

:::exercise{title="动手：故意死一次"}
故意让渲染线程提前退出，看检查能不能报出来。
:::
