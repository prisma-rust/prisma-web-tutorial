# 变换与位置

改一个位置字段，等于可变借用它的父对象。这条在Rust里是硬规则。

## 改字段要借父对象

```rust
// 改位置字段：要先可变借父对象，再写字段
(*go.transform).position = Vector3::new(0.0, 1.0, 0.0);
```

对照 C++：改字段直接走裸指针，不查借用。对照 C#：改字段走对象引用，也不查借用。Rust改字段要先证明同一时刻只有一个可变借用。

## 父对象被借，别人就不能再借

改字段的路上父对象被借了，回收站别的地方还拿着父对象的引用，编译器直接拦住。这不是脾气问题，是规则。

完成标准：你能说出改字段这一步借了谁。

:::exercise{title="动手：删一行看报错"}
故意在改字段之前借一次父对象，看编译器把哪一行拦下来。把行号记下来。
:::
