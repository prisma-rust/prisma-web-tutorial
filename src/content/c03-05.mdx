# 所有权不是垃圾回收

所有权管的是谁有权改，不是何时释放。

## 每块数据只有一个主人

主人离开作用域，数据就销毁。C++ 里释放靠人，错了就漏或双重释放。C# 里释放靠垃圾回收，时机不确定。锈语里释放的时机在编译期就定好了。

```rust
// 主人离开大括号，数据就在这里销毁
{
    let s = String::from("engine");
    println!("{s}"); // 还在主人手里能用
} // 到这里销毁，不用手动释放
```

## 先改主人，再谈释放

遇到数据归谁这个事，先把主人写成只有一个。主人多了，释放反而乱。

完成标准：你能说出所有权管的是谁在改，不是何时释放。

:::exercise{title="动手：数主人"}
找一块数据，看它有几个主人。把多余的主人删掉，看代码还顺不顺。
:::
